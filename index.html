Der API-Token wird nur lokal in diesem Browser gespeichert. Er wird ausschließlich beim Upload an Pastefy gesendet.

API-Schlüssel bei pastefy.app/apikeys erzeugen. Der Code wird als nicht-verschlüsselte Paste hochgeladen. Teile daher keine Geheimnisse.
